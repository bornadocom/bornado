# iOS Style Wheel Date Picker — Swiper.js + Vanilla JS

A Pen created on CodePen.

Original URL: [https://codepen.io/editor/EDMAN-center/pen/019cec31-3ffb-77e5-b268-fa50132c6f5e](https://codepen.io/editor/EDMAN-center/pen/019cec31-3ffb-77e5-b268-fa50132c6f5e).

A pixel-perfect iOS-style wheel date picker built from scratch — no libraries except Swiper for the momentum scroll and snap.

Three columns — month, day, year — all scroll with native iOS momentum and snap perfectly to the centre highlight band. Handles leap years and short months dynamically. Stores the confirmed date into a hidden input field, ready for any form.

✦ Pure CSS highlight band — no JS positioning tricks
✦ Leap year + short month handling — day column always shows the right count
✦ Momentum scroll + centre snap — powered by Swiper with custom config
✦ Confirm button stores selected value into a real input field
✦ Zero dependencies except Swiper
