# Bornado Ad Permalinks

پلاگین سفارشی برای ساختار URL آگهی‌های `AdForest` با فرمت زیر:

```text
/ad/{hashid}/{slug}
```

مثال:

```text
https://example.com/ad/Kx8b2/مبل-راحتی-هفت-نفره-در-حد-نو
```

## کاری که این پلاگین انجام می‌دهد

- تبدیل permalink آگهی‌های `ad_post` به ساختار `ad/{hashid}/{slug}`
- decode کردن `hashid` به `post ID` بدون ذخیره کردن hash در دیتابیس
- ریدایرکت `301` از URL قدیمی به URL جدید
- ریدایرکت `301` از slug قدیمی به slug جدید بعد از تغییر عنوان
- تثبیت canonical برای صفحه هر آگهی
- هم‌راستا کردن محدودیت طول عنوان آگهی با بازه `20` تا `80`

## نصب

1. پوشه `bornado-ad-permalinks` را داخل `wp-content/plugins/` قرار دهید.
2. مطمئن شوید `mu-plugin-loader.php` این پلاگین را `require` می‌کند.
3. یک بار در وردپرس به `Settings > Permalinks` بروید و `Save Changes` بزنید.

## تنظیم SALT

این پلاگین از constant زیر برای Salt استفاده می‌کند:

```php
define('BORNADO_AD_HASHIDS_SALT', 'replace-this-with-a-long-random-secret');
```

بهترین محل قرار دادن آن: `wp-config.php`

### نکات مهم درباره Salt

- `Salt` همان کلید ثابت ورودی برای تولید و decode کردن `Hash-ID` است.
- این مقدار باید **ثابت** باشد.
- بعد از اینکه سایت live شد، **نباید تغییر کند**.
- اگر Salt را عوض کنید، `Hash-ID` همه آگهی‌ها عوض می‌شود و URLهای قبلی دیگر معتبر نخواهند بود.

### Salt خوب چه ویژگی‌ای دارد؟

- طول مناسب: ترجیحاً حداقل `24` تا `48` کاراکتر
- غیرقابل حدس
- شامل ترکیبی از حروف بزرگ، حروف کوچک، عدد، و در صورت تمایل نمادها

### نمونه مناسب

```php
define('BORNADO_AD_HASHIDS_SALT', 'Bornado-2026!7xQp@4Lm#9RsT2vW8');
```

### نمونه نامناسب

```php
define('BORNADO_AD_HASHIDS_SALT', 'Bornado');
```

دلیل نامناسب بودن:

- خیلی قابل حدس است
- entropy پایینی دارد
- برای obfuscation حرفه‌ای انتخاب خوبی نیست

## اگر Salt را تعریف نکنیم چه می‌شود؟

پلاگین fallback داخلی دارد و از این ترکیب استفاده می‌کند:

- `wp_salt('auth')`
- `network_home_url('/')`

این fallback برای جلوگیری از ازکارافتادن سیستم مفید است، اما برای production بهتر است حتماً `BORNADO_AD_HASHIDS_SALT` را خودتان به‌صورت صریح تعریف کنید تا رفتار URLها کاملاً کنترل‌شده و پایدار باشد.

## تنظیم عنوان آگهی در AdForest

در تنظیمات AdForest گزینه `Ad Post title limit` را روی این عدد بگذارید:

```text
80
```

دلیل:

- بازه هدف این معماری `20` تا `80` کاراکتر است
- مقدار `80` بیشترین طول مجاز و مناسب برای URL را می‌دهد
- گارد سفارشی پلاگین هم اجازه نمی‌دهد عنوان از این بازه خارج شود

## رفتار عنوان آگهی

- کمتر از `20` کاراکتر: نامعتبر
- بیشتر از `80` کاراکتر: نامعتبر
- بین `20` تا `80` کاراکتر: معتبر

پلاگین هم در فرانت‌اند و هم در لایه AJAX ثبت آگهی این موضوع را enforce می‌کند.

## چک‌لیست تست بعد از استقرار

بعد از نصب، این موارد را تست کنید:

1. `get_permalink()` برای آگهی به فرم جدید برگردد
2. URL جدید آگهی باز شود
3. `hashid` نامعتبر به `404` برسد
4. URL قدیمی آگهی با `301` به URL جدید برود
5. بعد از تغییر عنوان، URL قبلی با `301` به URL جدید برود
6. مسیرهای semantic search/archive سایت همچنان درست کار کنند

## نکته مهم مهاجرت

اگر بعداً سایت از وردپرس به سیستم دیگری مهاجرت کند، تا وقتی همین `Salt` حفظ شود، می‌توان همان URLها را دوباره تولید کرد.
